# 🌱 植物大战僵尸 · 简化版 🧟

一个用纯 HTML + Canvas + JavaScript 实现的简化版《植物大战僵尸》,单文件、零依赖,双击 `index.html` 即可在浏览器中游玩。

## 🎮 玩法

- 点击画布开始游戏,共 **5 波** 僵尸,波数越高僵尸越多、越强
- 点击顶部卡片选择植物,再点击草地种植
- 僵尸走到最左侧则失败;撑过全部 5 波即胜利
- 击杀僵尸可获得分数

## 🌻 植物(6 种)

| 植物 | 阳光 | 作用 |
|---|---|---|
| 🌻 向日葵 | 50 | 定期产生阳光 |
| 🌱 豌豆射手 | 100 | 攻击本行僵尸 |
| ❄️ 寒冰射手 | 175 | 攻击并减速僵尸 |
| 🥜 坚果墙 | 50 | 高血量肉盾 |
| 🍒 樱桃炸弹 | 150 | 种下后延迟爆炸,范围伤害 |
| 🥔 土豆雷 | 25 | 25 阳光秒杀踩到的僵尸,需 10 秒上膛 |
| 🪏 铲子 | 免费 | 铲除已种下的植物 |

阳光会自动收集(落地约 2.5 秒后自动收入),无需手动点击。

## 🚀 运行

无需安装任何东西,直接用浏览器打开:

```bash
# macOS / Linux
open index.html

# 或者用任意静态服务器
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 🛠️ 技术说明

- 单文件 `index.html`,纯原生 JavaScript,无任何第三方库
- 游戏循环基于 `requestAnimationFrame`,逻辑与渲染分离
- 9×5 草地棋盘,植物/僵尸/子弹/粒子均为轻量对象池式管理
